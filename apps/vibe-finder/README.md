# Vibe Finder — launcher icon

This folder holds **only the PWA launcher icons** for the "Vibe Finder" tile on Eric's Apps.

Vibe Finder is a **private, token-gated** event-discovery app hosted on Railway — it is NOT a
hosted static app and its URL is intentionally **not** committed here (privacy guard: never put a
private app's URL in this public repo). It is surfaced as a **per-device private tile** via a
one-tap `#setup=` link (the same hybrid pattern as Class Booker): the icons live here (public,
just a glyph), the private URL lives only in the emailed setup link / each device's localStorage.

- Icons: `icon-any-{192,512}.png` (transparent glyph) · `icon-maskable-{192,512}.png` (green tile).
- Brand: Flourishing Ray — FR green `#002F10`, lime accent `#D8FC7B` (matches the app's masthead ✦).
- App + pipeline: `C:/code/find-us-an-event` (private repo).
